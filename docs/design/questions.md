### 決めたことに伴う注意点

次は、自分で決めたことが、他の回答や仕様とぶつかる、またはまだ決まっていないことを残すものです。設計書を書くときに、あらためて扱います。

- **Q-11 と R-01**: 全チャンネルで同名を禁止すると、他人のプライベートチャンネルと同じ名前を付けようとしたとき、エラーで「その名前の部屋がある」ことが分かります。名前を順に試せば、どんな名前の部屋があるかも探れます。R-01 の「存在自体が分からない」を、この点だけあきらめる決定です。クライアントには伝えていません
- **Q-13 の並びの規則**: 名前順は、文字コード順か五十音順かが決まっていません。設計で決めます
- **Q-21 と JavaScript**: 「さらに読み込む」で上に足すには JavaScript が必要です。JavaScript を使うかの判断（`design-guide.md` §5）は、まだ決めていません
- **Q-26 と Q-21**: 該当メッセージが最新50件より前にあるとき、その位置を含む範囲を開く処理が要ります
- **Q-27・Q-28**: 候補の一覧と、メンバーを外す確認は、モックアップにない画面です。`screens.md` で作ります
- **Q-34 の日時**: 初期データの作成時に相談して決めます
- **R-12 と Q-29**: 登録できるメールアドレスの範囲が決まっていません
